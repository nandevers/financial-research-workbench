# Portfolio design continuity

The workbench shares the visual language of [Fernando Barbosa's portfolio](https://nandolab.github.io/). The live portfolio and its `assets/css/portfolio.css` were checked on 26 October 2026.

The shared core tokens are ink `#111318`, navy `#081b41`, blue `#0c2d69`, muted text `#586374`, borders `#d9dfe8`, pale surface `#f3f5f8`, and white. Georgia / Times New Roman provides editorial headings; Segoe UI / Arial provides interface and body text. Fonts use system stacks, without a remote font dependency.

The circular `fb.` identity links home. White surfaces, navy selected navigation, blue links, restrained four-pixel corners, and thin gray dividers connect the workspace to the portfolio. Content stays left aligned. The research workspace retains its investigation, memo, and source-reader columns; narrow screens collapse the navigation and display the source reader as an overlay.

Model markers use a blue/slate scale drawn from the portfolio. Their numbers and labels identify checkpoints without relying on color alone. Hollow markers continue to identify failed output validation. Amber is reserved for recorded failures and review warnings. Blue highlights in source excerpts match the portfolio's text-highlight treatment.

This presentation update does not alter recorded model outputs, metrics, source passages, or evaluation claims. Verification covers the production build, public snapshot checks, and visual inspection of investigations, comparison, source reading, library, evaluation, and mobile layouts.
